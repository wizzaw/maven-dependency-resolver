How to Push Bundle to an Air-Gapped Nexus

Every downloaded ZIP bundle automatically includes upload.sh (Linux/macOS), upload.ps1 (Windows PowerShell), manifest.json, and resolution-report.txt.

1. Transfer & Extract in Air-Gap

unzip maven-airgap-bundle-*.zip -d maven-bundle
cd maven-bundle

2. Linux / macOS (Bash + curl)

Requires only curl (no Maven installation needed on the bastion host). Works identically for both M2 and FLAT layouts:

chmod +x upload.sh

# Optional: preview all PUT requests first
DRY_RUN=true NEXUS_URL="https://nexus.internal/repository/maven-releases" ./upload.sh

# Execute upload to Nexus Maven 2 Hosted Repository
NEXUS_URL="https://nexus.internal/repository/maven-releases" \
NEXUS_USER="admin" \
NEXUS_PASS="your-password" \
./upload.sh

3. Windows (PowerShell)

.\upload.ps1 `
  -NexusUrl "https://nexus.internal/repository/maven-releases" `
  -Username "admin" `
  -Password "your-password"
